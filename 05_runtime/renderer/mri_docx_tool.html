이 페이지가 다른 화면 안에 끼워진 상태로 열려 있습니다. 보안 정책 때문에 파일 저장이 막힐 수 있습니다. 저장이 안 되면 서식 그대로 복사를 쓰시거나, 이 파일을 내려받아 더블클릭으로 여십시오.

알아두실 것

여러 이슈를 한 문서로결과 JSON을 이어서 붙여넣거나 파일 여러 개를 끌어다 놓으면, 표지와 이슈별 섹션으로 나뉜 문서 하나가 만들어집니다. 이슈마다 새 페이지에서 시작합니다.
서식 그대로 복사 버튼파일 저장이 막힌 PC를 위한 대안입니다. 누른 뒤 한글이나 Word에 바로 붙여넣으면 굵기와 들여쓰기가 유지됩니다.
추적정보 포함최종 준비도, 사용된 근거·전략 개수, 원문 핵심 주제 중 반영된 것과 못 찾은 것을 마지막 장에 표로 붙입니다. 내부 검수·시연용이며 제출본에는 넣지 않는 것이 기본입니다.
한글(HWP)로 내야 할 때Word 파일을 만든 뒤 한글에서 열어 HWP로 저장하세요. HWP를 직접 만드는 것보다 안정적입니다.
이 페이지를 보관하려면브라우저에서 Ctrl+S 로 저장해두면 인터넷 없이도 언제든 더블클릭해서 씁니다.
JSON 일부만 복사한 경우"본문을 찾지 못했습니다" 오류가 납니다. 코드블록 안쪽을 처음부터 끝까지 다시 복사하세요.
입력한 내용은 이 브라우저 안에서만 처리되며 외부로 전송되지 않습니다.
동일한 변환 규칙의 명령줄 버전: 05_runtime/renderer/render_mri_docx.js
