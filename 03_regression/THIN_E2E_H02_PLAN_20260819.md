# Thin End-to-End Test Plan — H02 Pet Industry

_Date: 2026-08-19_
_Status: READY_

## Objective

Run one screened MRI issue manually from validated issue through final MRI response v0.

Do not freeze BO or downstream schemas before this test.

## Case

H02 / pet-industry activation.

Primary failure pattern to watch:
```text
industry growth → immediate ETF/product recommendation
```

The test should instead require investability / demand / market / company-state evidence before Strategy.

## Input Boundary

Initial BO input:
- analysis_as_of_date
- validated issue
- screening result

Forbidden BO initial input:
- company state
- department response
- internal product data
- market-intelligence results

## Manual Sequence

### 1. BO v0
Generate:
- small number of BOs
- assumptions
- evidence questions
- validation priority

### 2. Market / Competitor Questions
Generate only questions needed to describe:
- market response
- competitor / peer actions
- related product supply
- relevant policy / industry movement

### 3. Shared Research Registry
Merge BO-validation and Market-Intel questions.

Mark:
- duplicate
- mergeable
- distinct

### 4. Evidence Retrieval
For this first test, manual or web research is acceptable.

Capture:
- evidence ID
- source class
- date
- claim supported
- purpose tag

### 5. Company State
Use available internal information or explicit placeholder statuses.

If internal access is unavailable:
- use UNKNOWN / NOT_AVAILABLE
- do not invent current company facts.

### 6. Evidence / State Integration
Produce:
- validated BO
- market / competitor summary
- company-state summary
- unresolved contradictions / unknowns

### 7. Gap
Compare validated opportunity vs Company State.

### 8. Strategy
Generate response direction only after Gap.

### 9. Final MRI Response v0
Fill:
`06_project_docs/contracts/FINAL_MRI_RESPONSE_SCHEMA_v0.md`

## Pass Criteria

- no growth → ETF shortcut
- BO initial generation is company-blind
- cross-lane duplicate research is visible
- unknown / not-found is not converted to absence
- final response contains both current status and response direction
- every material external/internal factual claim has provenance
- department response may be pending without blocking the AI analysis
- the result is practically usable as the analyst's own MRI response draft

## Post-Test Review

Record:
- fields used
- fields unused
- fields missing
- duplicated searches
- missing data interfaces
- schema changes
- candidate physical-Agent boundaries

Only after this review:
- BO Prompt v1
- Company State Contract v1
- Market Intel Contract v1
- Shared Router Contract v1
